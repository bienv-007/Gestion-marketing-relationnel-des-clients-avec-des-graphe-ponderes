Gestion MLM est une application de gestion de marketing relationnel 
On peut créer des relations entre client c'est a dire chaque client a une filleul ou un parrain 
le parrain touche 5% de commissions sur les achats de ses filleuls directes et 1% de commissions
sur ses filleuls indirectes donc les filleuls de ses filleuls
l'application permet aussi d'ajouter des achats et de visualiser 
le réseau des clients via un graphe pondéré

technologies utilisees : PHP et MySQL
